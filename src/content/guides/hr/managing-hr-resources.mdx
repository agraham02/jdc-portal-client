## HR Resources Overview

The **HR Resources** section serves as a centralized library for company documents and useful links. As an HR team member, you can upload documents, manage categories, and maintain the resource library for all employees.

## Accessing HR Resources

<StepList>
  <Step number={1} title="Navigate to HR Resources">
    Go to **HR Resources** in the **HR** sidebar section. You'll see the main HR Resources page with two tabs: **Documents** and **Links**.
  </Step>
  <Step number={2} title="View Statistics">
    The stats cards at the top show:
    - **Total Documents** — Number of documents in the library
    - **Recent Uploads** — Documents added in the past week
    - **Total Downloads** — All-time download count
  </Step>
</StepList>

## Uploading Documents

<StepList>
  <Step number={1} title="Go to Upload Page">
    From the HR Resources page, click the **Upload** button to navigate to the upload page.
  </Step>
  <Step number={2} title="Select a File">
    Choose the document you want to upload. Supported formats typically include PDF, Word documents, Excel spreadsheets, and images.
  </Step>
  <Step number={3} title="Add Metadata">
    Enter a **title**, **description**, and select a **category** for the document. Adding descriptive tags helps employees find the document later.
  </Step>
  <Step number={4} title="Upload">
    Click **Upload** to submit the document. The file will be automatically scanned for security before being added to the library.
  </Step>
</StepList>

<Callout variant="info" title="Virus Scanning">
  All uploaded files are automatically scanned for viruses and malware. If a file fails the scan, it will be rejected and you'll be notified. This protects all portal users.
</Callout>

## Managing Categories

Categories help organize documents and make them easier to find.

<StepList>
  <Step number={1} title="Navigate to HR Categories">
    Go to **HR Categories** in the **HR** sidebar section (this may require specific permissions).
  </Step>
  <Step number={2} title="View Existing Categories">
    You'll see all current document categories with their names and descriptions.
  </Step>
  <Step number={3} title="Create a Category">
    Click **New Category** to add a new category. Enter a **name** and optional **description**.
  </Step>
  <Step number={4} title="Edit or Delete">
    Click on an existing category to edit its details or delete it if it's no longer needed.
  </Step>
</StepList>

<Callout variant="warning" title="Deleting Categories">
  Before deleting a category, make sure no active documents are assigned to it. Documents in a deleted category may become harder for employees to find.
</Callout>

## Document Library Features

The document library provides employees with:

- **Search** — Find documents by title, description, or tags
- **Category Filtering** — Browse documents by category
- **Download** — Click to download any document
- **Links Tab** — A separate tab for external resource links (payroll systems, benefits portals, etc.)

## Best Practices

- **Use clear titles** — Document titles should be descriptive so employees can find them easily
- **Categorize consistently** — Assign every document to the most appropriate category
- **Update regularly** — Remove outdated documents and upload current versions
- **Add tags** — Tags improve searchability — include terms employees might search for
